## 🚀 Run the exercises

You’ll need Python 3 installed. These scripts use only Python’s built-in features, so no extra packages are required.

```bash
python "Python_code_01 (intro).py"
python "Python_code_02 (work with str).py"
```

On some systems, use `python3` instead of `python`.
