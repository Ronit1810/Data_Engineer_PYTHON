## 🗂️ Repository contents

### [`Python_code_01 (intro).py`](./Python_code_01%20%28intro%29.py)

An introductory script for practicing Python output, basic values, and simple interaction.

Topics covered:

- **Printing and escape sequences:** use `print()` and special characters such as `\n`, `\t`, quotes, and `\\` to format output.
- **Variables and strings:** assign a name to a variable and combine strings with the `+` operator.
- **User input:** collect a name with `input()` and print a personalized greeting.
- **Basic data types:** compare integer addition (`10 + 30`) with string concatenation (`"10" + "30"`).

### [`Python_code_02 (work with str).py`](./Python_code_02%20%28work%20with%20str%29.py)

A hands-on guide to Python types and common string operations, with examples and a small data-cleaning challenge.

Topics covered:

- **Types and conversion:** inspect values with `type()` and convert a number to text with `str()`.
- **String length and counting:** use `len()` and `count()` to measure text and find repeated content.
- **Transforming and formatting:** replace text with `replace()`, join strings with `+`, and insert values with f-strings.
- **Splitting and repetition:** split a timestamp with `split()` and repeat text with `*`.
- **Indexing and slicing:** access characters by position and select parts of a string.
- **Cleaning and case conversion:** remove surrounding whitespace with `lstrip()`, `rstrip()`, and `strip()`, and change case with `lower()` and `upper()`.
- **Searching:** check prefixes and suffixes with `startswith()` and `endswith()`, find a substring with `find()`, and test membership with `in`.
- **Validation:** check alphabetic and numeric strings with `isalpha()` and `isnumeric()`.
- **Text-cleaning challenge:** clean a formatted string and extract a name, role, and age using string methods.

## 🚀 Run the exercises

You’ll need Python 3 installed. These scripts use only Python’s built-in features, so no extra packages are required.

```bash
python "Python_code_01 (intro).py"
python "Python_code_02 (work with str).py"
```

On some systems, use `python3` instead of `python`.
